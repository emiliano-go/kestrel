# Kestrel on...

### VirtualBox

VirtualBox is a popular VM runner. [You can run Kestrel inside that too](https://github.com/emiliano-go/kestrel/discussions/176). But performance probably won't be great.

### VMware Workstation on Windows 11

Another popular VM runner for Windows. [Kestrel has been setup inside of that as well](https://github.com/emiliano-go/kestrel/discussions/572).

### Steam Deck

The Steam Deck runs on Arch, which means you can run Kestrel on your Steam Deck. Altynbek Orumbayev has [a full setup script and explanation on how to do it](https://github.com/aorumbayev/deckarchy). How cool is that!

### NixOS

Kestrel is really Arch + Hyprland, but Henry Sipp has [ported the essence of the setup to NixOS](https://github.com/henrysipp/kestrel-nix). So if you've been nix-pilled, here's a good starting point. It may or may not stay up-to-date with the latest Kestrel changes, but it's pretty cool none the less!

### Something else!

If you're trying to get Kestrel running on a configuration that isn't the default, you should join the #kestrel-on-other channel on [our community Discord](https://discord.gg/tXFUdasqhY).
